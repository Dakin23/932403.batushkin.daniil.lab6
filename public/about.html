Описание приложения

"КиноРейтинг" - список фильмов с оценками. Главная страница получает данные с собственного API и позволяет отфильтровать фильмы по минимальному рейтингу. Приложение устанавливается как PWA и работает офлайн: статика и последний полученный список фильмов кешируются service worker.

Параметры /api/movies

ПараметрГдеТипДопустимые значения
minRating query-строка число (дробное) от 0 до 10; разделитель — точка или запятая
  • Без параметра возвращается весь список фильмов.
  • С параметром — только фильмы, у которых rating >= minRating.
  • В обоих случаях результат отсортирован по rating по убыванию; при равных оценках — по названию по алфавиту.
  • Имена параметров чувствительны к регистру: minrating не распознаётся и игнорируется (вернётся весь список).

Формат ответа

Массив объектов. Поля одного элемента:

ПолеТипОписание
titlestringНазвание фильма
yearnumber (целое)Год выпуска
ratingnumberРейтинг по шкале 0–10

Пример запроса

GET /api/movies?minRating=9

Пример ответа (200 OK)

[
  { "title": "Побег из Шоушенка", "year": 1994, "rating": 9.3 },
  { "title": "Крёстный отец",     "year": 1972, "rating": 9.2 },
  { "title": "Тёмный рыцарь",     "year": 2008, "rating": 9.0 }
]
