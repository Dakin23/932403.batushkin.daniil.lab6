# 932403.batushkin.daniil.lab6

Лабораторная работа №6. Введение в Node.js и базовый сервер на Express
Цель: освоить запуск Node.js-приложений, работу с модулями, создание простого
HTTP-сервера, а также превращение статического сайта в PWA (устанавливаемое
приложение с офлайн-режимом).

## Вариант 15

Тема «Список фильмов с рейтингом». Маршруты: GET /, GET /about,
GET /api/movies. Данные — массив фильмов (title, year, rating). Query-параметр
?minRating= фильтрует список по минимальной оценке, без параметров отдаются все
фильмы, отсортированные по рейтингу по убыванию, пустой результат — пустой массив.

## Запуск

```bash
npm install
npm start
```

## Маршруты

- GET / — список фильмов с фильтром по минимальному рейтингу;
- GET /about — страница «О себе»;
- GET /api/movies — все фильмы, отсортированные по рейтингу по убыванию
  (при равных оценках — по названию по алфавиту);
- GET /api/movies?minRating=9 — фильмы с рейтингом не ниже 9;
- GET /api/movies?minRating=8.5 — дробные значения, разделитель точка или
  запятая (8,5 — то же самое);
- GET /api/movies?minRating=10 — пустой результат — [] со статусом 200;
- невалидный minRating (abc, пусто, 11, -1, параметр передан дважды) — 400 и
  { error: "..." };
- неизвестный маршрут — 404 и { error: "Not Found" }.

## PWA

- manifest.json — имя, иконки 64/192/512 + maskable, display: standalone;
- sw.js — кеширует статику и список фильмов, работает офлайн;
- офлайн: статика из кеша, /api/movies — сеть, при отсутствии сети фильтрация
  по закешированному списку с заголовком X-Offline, неизвестная страница —
  offline.html.

После изменения css/js/иконок нужно поднять VERSION в public/sw.js, иначе
браузер отдаст старые файлы из кеша.
